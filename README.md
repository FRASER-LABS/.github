# FRASER-LABS/.github

Org-wide defaults for every Fraser Labs repo that doesn't define its own:

- `profile/README.md`: the org's public profile page.
- `.github/ISSUE_TEMPLATE/`: issue forms (weekly update, broker scope request, bug).
- `.github/pull_request_template.md`: the PR checklist and branch rule.

A repo with its own `.github/ISSUE_TEMPLATE/` or PR template uses those instead.
This repo is **public**, because GitHub only reads org defaults from a public
`.github` repo, so nothing private goes here. Tracked in FRASER-LABS/team CONTRACT T-014.
