## Fraser Labs

Tim Fraser's research lab at Cornell Systems Engineering. We build production
data systems for public-interest clients: air quality, transportation emissions,
and environmental sensing.

| Project | What it is |
|---|---|
| **SAFECAST** | A rebuilt public map and API over Safecast's open radiation measurements (CC0). |
| **MOVESAI / CAT** | Fast emissions estimates for transportation planning, and the CAT platform around them. |
| **CIVIC / CP Portal** | Congestion-pricing and air-quality analysis. |

The lab's MEng engineers work in these repos alongside Tim. Lab members start at the
`team` repo.
